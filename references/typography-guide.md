# 中文字宽估算表

排版前快速估算文本占用宽度，避免溢出和意外换行。

## 核心公式

### 中文全角字符

```
单字宽度 ≈ font-size
```

示例：`font-size: 36px` → 每个中文字约占 36px 宽。

### 英文 / 数字 / 等宽字符

```
单字符宽度 ≈ 0.6 × font-size
```

示例：`font-size: 36px` → 每个英文/数字约占 21.6px 宽。

### 混合文本

```
估算宽度 = 中文数 × fontSize + 英文数 × 0.6 × fontSize + 内边距
```

## 常用场景速查（1080 宽画布）

| 场景 | 字号 | 单字宽 | 最大字数（含 padding） | 备注 |
|------|------|--------|----------------------|------|
| 封面大标题 | 72px | 72px | ~12 字 | 12 × 72 = 864 + padding |
| 卡片小标题 | 48px | 48px | ~16 字 | 16 × 48 = 768 |
| 卡片正文 | 36px | 36px | ~21 字/行 | 21 × 36 = 756 |
| 表格表头 | 30px | 30px | 按列宽计算 | 用 table-layout: fixed |
| 代码字号 | 24px | — | 等宽，0.6 × 24 | 保证不横向溢出 |
| 底部说明 | 26px | 26px | ~28 字 | 底部区域 padding 较大 |

## 表格列宽计算公式

```
列宽 = 最长文本估算宽度 + 左右内边距(各 12px)
     = max(该列每个单元格的估算宽度) + 24
```

**强制约束**：总列宽之和必须 ≤ 可用区域宽度。如果超出，要么减小字号，要么精简文案。

## 实战自检

写 HTML 前，把每张卡片的关键文本（标题、表格单元格、代码块）用上面的公式过一遍。如果估算值接近容器宽度，先调整字号或文案，不要等截图出来再返工。
