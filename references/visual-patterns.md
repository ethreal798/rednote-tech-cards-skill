# 版式范式库（Visual Patterns）

设计系统（design-tokens.md）解决"用什么色、多大字"；本文件解决**"怎么构图"**。

规则：**每张卡片从本库选一个范式**，不要每次从零设计版面。选型依据 = 步骤 1 分镜的知识类型。

## 选型对照表

| 知识类型 | 推荐范式 | 特征 |
|---------|---------|------|
| 封面/总览 | 范式 A · 中心放射 | 中心胶囊 + 四角要素 |
| 对比（A vs B） | 范式 B · 左右对照 | 双卡 + 中间箭头 |
| 流程/生命周期 | 范式 C · 纵向时间线 | 编号锚点 + 箭头串联 |
| 原理/层次 | 范式 D · 三层层叠 | 自下而上堆叠 + 箭头 |
| 陷阱/正误 | 范式 B 变体 | 红绿玻璃卡对照 |
| 规模/数量 | 范式 E · 数据矩阵 | 玻璃表格 + 高亮表头 |

---

## 范式 A · 中心放射（封面专用）

**适用**：封面页、总览页、单图讲一个核心概念。

**布局**：

```
┌──────────────────────────────┐
│  [tag 标签]                   │
│  主标题                       │
│  副标题（含1个青色高亮词）     │
│  ┌────────┐ ┌────────┐      │
│  │ 要素①  │ │ 要素②  │      │
│  └────────┘ └────────┘      │
│        ┌────────────┐       │
│        │ 中心徽章    │ ← 渐变胶囊
│        │ (核心结论)  │   + 发光
│        └────────────┘       │
│  ┌────────┐ ┌────────┐      │
│  │ 要素③  │ │ 要素④  │      │
│  └────────┘ └────────┘      │
│  ──── 分隔线 ────            │
│  底部结语（情感化一句话）      │
└──────────────────────────────┘
```

**关键 CSS**：
- 中心徽章：`border-radius: 999px` + `--grad-accent` + `--shadow-lg`
- 四角要素：`.bglass` 玻璃卡
- 分隔线：`linear-gradient(90deg, transparent, rgba(255,255,255,0.22), transparent)`

## 范式 B · 左右对照

**适用**：A vs B 对比、正误对照、前后快照。

**布局**：

```
┌──────────────────────────────┐
│  [tag] 主标题 副标题          │
│  ┌─────────┐ →  ┌─────────┐  │
│  │ 左要素   │    │ 右要素   │  │
│  │ (冷色/灰)│    │ (红色高亮)│  │
│  └─────────┘    └─────────┘  │
│  第二组对照（可选）            │
│  ┌─────────┐    ┌─────────┐  │
│  └─────────┘    └─────────┘  │
│  ──── 分隔线 ────             │
│  一句话收尾                   │
└──────────────────────────────┘
```

**关键 CSS**：
- 左右卡 `flex:1`，中间箭头 `font-size:44px; color: var(--accent-hi)`
- 左卡默认 `bglass`，右卡 `bglass.red` 强调"变化/结果"
- 卡内列表用 `<br>` 分行，保证两卡行数对等，视觉平衡

## 范式 C · 纵向时间线

**适用**：流程、生命周期、步骤序列、因果链。

**布局**：

```
┌──────────────────────────────┐
│  [tag] 主标题 副标题          │
│  ┌───┐ ┌───────────────┐    │
│  │ 01│ │ 阶段①标题      │    │
│  │    │ │ 描述文字       │    │
│  └───┘ └───────────────┘    │
│          ↓                   │
│  ┌───┐ ┌───────────────┐    │
│  │ 02│ │ 阶段②          │    │
│  └───┘ └───────────────┘    │
│          ↓（重点阶段红高亮）  │
└──────────────────────────────┘
```

**关键 CSS**：
- 每个阶段：`.bglass` + 左侧 `--num` 编号锚点
- 步骤间箭头：`text-align:center; color: var(--accent-hi); font-weight:900`
- **重点阶段**：`.bglass.red`（红边框 + 红底）高亮
- **终点阶段**：`.bglass.cy` + `--num-cyan` 表示收尾
- 5 个阶段是上限（纵向 1440px 画布），超过拆两张

## 范式 D · 三层层叠

**适用**：原理讲解、机制拆解、自下而上的依赖关系。

**布局**：

```
┌──────────────────────────────┐
│  [tag] 主标题 副标题          │
│  ┌─ 顶层（结果/输出）红色 ─┐  │
│  │  + pill 标签组          │  │
│  └────────────────────────┘  │
│            ↑ 箭头文字         │
│  ┌─ 中层（机制/加权）──────┐  │
│  │  原理描述               │  │
│  └────────────────────────┘  │
│            ↑ 箭头文字         │
│  ┌─ 底层（上下文/输入）───┐   │
│  │  + 玻璃表格             │  │
│  └────────────────────────┘  │
│  ──── 分隔线 ────            │
│  核心结论（红色加粗开头）      │
└──────────────────────────────┘
```

**关键 CSS**：
- 顶层 `.bglass.red`（结果层）、中底 `.bglass`（机制层）
- 箭头文字用 `--cyan` 青色，表示"向上因果"
- 底层容器内嵌表格（`table-layout: fixed` + `<colgroup>`）
- 三层是上限，再多拆成两张

## 范式 E · 数据矩阵

**适用**：对比表、属性清单、多行多列数据。

**布局**：

```
┌──────────────────────────────┐
│  [tag] 主标题 副标题          │
│  ┌── 玻璃容器 ──────────────┐ │
│  │ 表头行（白字+浅灰底）     │ │
│  │ 数据行1（首列红色加粗）   │ │
│  │ 数据行2                  │ │
│  │ 数据行3                  │ │
│  └──────────────────────────┘ │
│  记忆金句卡（红色玻璃）        │
│  底部一句话                   │
└──────────────────────────────┘
```

**关键 CSS**：
- 表格容器 `.bglass`，内边距收窄（`padding: 8px 20px 20px`）
- 表头：`background: rgba(255,255,255,0.06)` + 底部 `border-bottom: 1px solid rgba(255,45,85,0.3)`
- 首列 `<b>` 红色加粗，建立阅读锚点
- 金句卡：`.bglass.red` + 大字号（34-38px）双行金句

## 通用质感清单（所有范式通用）

每张卡都必须包含以下元素，缺一即"平"：

1. **背景层次**：渐变 + 光斑（`body::before`）+ 网格（`body::after`）
2. **视觉锚点**：编号锚点（`--num`）或红色竖条标题（`.block-title::before`）
3. **玻璃层次**：`.bglass` 玻璃卡 + 阴影（`--shadow-md`）
4. **疏密节奏**：区块间距 40-48px，卡内间距 12-26px，别全用同一个值
5. **高对比文字**：深色底必须用 `--ink-1/2/3` 三级白字，禁止低对比灰字
6. **收尾**：底部结论句（一句情感化的话）或金句卡
